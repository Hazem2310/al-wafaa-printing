- رقم اتصال مباشر: 052-6269162، إنستغرام @gr.alwafaa.

## ابدأ من هنا

اقرأ [START-HERE-AR.md](START-HERE-AR.md) لخطوات الإعداد والنشر. يتطلب Node.js 22.13 أو أحدث.

```bash
npm install
npm run setup
npm run dev
```

الإدارة: `/admin`، المعرض: `/catalog`.

على Netlify استخدم GitHub ومحول Next.js. اضبط ADMIN_PASSWORD وADMIN_SESSION_SECRET وCATALOG_STORAGE=netlify في إعدادات البيئة. **لا ترفع .next يدويًا ولا تستخدم static export.**

محليًا التخزين في `.wafaa-data`؛ على Netlify التخزين في Blobs. لا توجد كلمة مرور افتراضية ولا تحفظ المنتجات في localStorage. يُستخدم localStorage فقط لاستيراد إضافات النسخة السابقة.

فحص البناء وسلوك API ضد خادم اختبار محلي معزول:

```bash
npm run test:catalog
```

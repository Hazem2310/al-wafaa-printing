# مطبعة الوفاء | דפוס אל-ופאא

موقع رسمي ثنائي اللغة (عربي / عبري) لمطبعة الوفاء في كفركنا.

## المحتوى

- واجهة فاخرة بأسلوب أسود وذهبي مع حركة وعمق 3D.
- تصميم متجاوب بالكامل للموبايل، مع قائمة مخصصة وزر اتصال ثابت.
- زر تبديل فوري بين العربية والعبرية.
- أقسام: تصاميم المدارس، الهدايا، الأقلام المخصصة، اللافتات، الأعراس، وكروت الأعراس.
- رقم اتصال مباشر: 052-6269162.

## تشغيله على السيرفر

يتطلب السيرفر Node.js 22 أو أحدث.

1. ارفع مجلد المشروع كاملًا إلى السيرفر.
2. من داخل المجلد شغّل:

    npm ci
    npm run build
    npm run start

للتجربة على جهازك:

    npm run dev

## تغيير الصور أو النصوص

- الصور موجودة في public/images/.
- النصوص العربية والعبرية موجودة في app/page.tsx.
- كل الألوان والحركة والتجاوب موجودة في app/globals.css.
